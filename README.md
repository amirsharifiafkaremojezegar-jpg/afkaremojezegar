# افکار معجزه‌گر

وب‌سایت فارسی و راست‌چین «افکار معجزه‌گر» با طراحی واکنش‌گرا و رنگ‌بندی سرمه‌ای و طلایی.

## فایل‌های اصلی
- `index.html`: صفحه اصلی سایت؛ بدون نیاز به نصب بسته یا فرایند build.
- `admin/index.html`: ورودی بخش مدیریت محتوا.
- `admin/config.yml`: ساختار مجموعه‌های محتوایی برای Decap CMS.

## بخش‌های قابل مدیریت
- فایل‌های صوتی و پادکست‌ها
- آموزش‌های ویدیویی
- مقالات و مطالب آموزشی
- داستان‌های موفقیت
- زندگینامه افراد موفق
- دوره‌های رایگان و آموزشی

## انتشار رایگان با GitHub Pages
1. در مخزن وارد **Settings → Pages** شوید.
2. در بخش **Build and deployment**، گزینه **Deploy from a branch** را انتخاب کنید.
3. شاخه `main` و پوشه `/ (root)` را انتخاب و **Save** کنید.
4. پس از چند دقیقه نشانی انتشار در همان صفحه نمایش داده می‌شود.

## وضعیت پنل مدیریت
ساختار اولیه CMS و دسته‌بندی محتوا آماده شده است؛ اما ورود امن هنوز فعال نیست. GitHub برای اتصال Decap CMS به مخزن به یک سرویس OAuth سمت سرور نیاز دارد. تا زمانی که OAuth به‌درستی پیکربندی و آزمایش نشده، نباید توکن یا رمز عبور در فایل‌های عمومی سایت قرار گیرد و امکان انتشار از پنل فعال نیست.

برای فعال‌سازی باید یک میزبان امن OAuth (مثلاً Cloudflare Worker) و یک GitHub OAuth App تنظیم شوند. شناسه و رمز برنامه باید فقط در تنظیمات محرمانه میزبان قرار گیرند، نه در مخزن عمومی. پس از آن ورود مدیر، ذخیره محتوا و بارگذاری رسانه باید آزمایش شود.

## نکته‌های تکمیلی
- آرشیوها با محتوای واقعی و مجاز برای انتشار تکمیل می‌شوند.
- دامنه اختصاصی مانند `afkaremojezegar.com` یا `afkaremojezegar.ir` رایگانِ تضمین‌شده نیست و ثبت آن ممکن است هزینه داشته باشد.
- در نسخه فعلی از نشان نوشتاری موقت استفاده شده؛ برای قراردادن لوگوی اصلی باید فایل تصویر لوگو به مخزن اضافه شود.
