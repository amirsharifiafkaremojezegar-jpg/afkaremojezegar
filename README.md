# افکار معجزه‌گر

وب‌سایت فارسی و راست‌چین «افکار معجزه‌گر» با طراحی واکنش‌گرا و رنگ‌بندی سرمه‌ای و طلایی.

## فایل اصلی
- `index.html`: صفحه اصلی سایت؛ بدون نیاز به نصب بسته یا فرایند build.

## انتشار رایگان با GitHub Pages
1. در مخزن وارد **Settings → Pages** شوید.
2. در بخش **Build and deployment**، گزینه **Deploy from a branch** را انتخاب کنید.
3. شاخه `main` و پوشه `/ (root)` را انتخاب و **Save** کنید.
4. پس از چند دقیقه نشانی انتشار در همان صفحه نمایش داده می‌شود.

## نکته‌های تکمیلی
- این نسخه، پوسته اولیه سایت است؛ بخش‌های صوتی، پادکست، ویدیو، مقالات و داستان‌های موفقیت هنوز محتوای واقعی ندارند و باید فایل‌ها و متن‌های مجاز برای انتشار بارگذاری شوند.
- پنل مدیریت محتوای روزانه هنوز راه‌اندازی نشده است. برای ورود امن مدیر و بارگذاری از موبایل به سرویس مدیریت محتوا و تنظیم دسترسی نیاز داریم.
- دامنه اختصاصی مانند `afkaremojezegar.com` یا `afkaremojezegar.ir` رایگانِ تضمین‌شده نیست و ثبت آن ممکن است هزینه داشته باشد.
- در این مرحله از نشان نوشتاری موقت استفاده شده؛ برای قراردادن لوگوی اصلی باید فایل تصویر لوگو به مخزن اضافه شود.
